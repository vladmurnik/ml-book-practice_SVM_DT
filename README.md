# Machine Learning: Decision Trees & Support Vector Machines

## 📌 Overview

This repository contains Jupyter Notebook examples demonstrating two popular machine learning algorithms using the Scikit-Learn library:

* **Decision Trees (DT)**
* **Support Vector Machines (SVM)**

The notebooks use the Iris dataset and synthetic datasets to illustrate classification concepts, model training, and decision boundaries.

---

## 📂 Repository Structure

```text
.
├── DT.ipynb     # Decision Tree classification example
└── SVM.ipynb    # Support Vector Machine examples
```

---

## 🌳 Decision Tree (DT)

The `DT.ipynb` notebook demonstrates:

* Loading the Iris dataset
* Selecting petal length and petal width features
* Training a Decision Tree classifier
* Configuring tree depth
* Performing classification using Scikit-Learn

### Technologies

* Python
* Scikit-Learn

---

## ⚡ Support Vector Machine (SVM)

The `SVM.ipynb` notebook demonstrates:

* Linear SVM classification
* Feature scaling with `StandardScaler`
* Binary classification on the Iris dataset
* Non-linear classification using the Moon dataset
* Polynomial feature transformation
* Polynomial kernel SVM
* Radial Basis Function (RBF) kernel SVM
* Visualization of decision boundaries

### Technologies

* Python
* NumPy
* Matplotlib
* Scikit-Learn

---

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/vladmurnik/ml-book-practice_SVM_DT
cd ml-book-practice_SVM_DT
```

Install dependencies:

```bash
pip install numpy matplotlib scikit-learn jupyter
```

---

## ▶️ Running the Notebooks

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open:

* `DT.ipynb`
* `SVM.ipynb`

and run the cells sequentially.
